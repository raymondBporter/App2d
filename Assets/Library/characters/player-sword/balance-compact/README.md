# Compact balance previews

`comparison.gif` compares the two small-correction loops at their exported
timing: eight frames and two seconds each. The individual GIFs and
`contact-sheet.png` are review aids. Platform shapes are preview annotations.

Both clips face right. One plants the screen-left foot, the other plants the
screen-right foot. The sword remains in the same hand in both actions.

The durable editable source, export settings, cached renders, and complete
workflow guide are in `Assets/Sources/characters/player-sword`. The normal asset
build imports these clips into `Assets/Runtime/characters/player-sword`.

`checks.json` records stable foot-contact pixels, complete frames without
clipping, and comparisons with three original supplied sprites. These previews
use the same normalization as the runtime importer, cropped only for viewing.
