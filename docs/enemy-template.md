# Enemy name

Status: playable first pass / tuning / accepted. Stable ID: `enemy-id`.

## Player decision

Role, pressure, visible tell, commitment point, guaranteed escape, punish window.
Normal-hit interruption, death during attack, and projectile-after-death rules.

## Behavior and tuning

State sequence. Detection/attack/retreat distances, terrain rules, movement speed,
action markers/durations, cooldown, damage, health. Name each unit.

## Editable assets and provenance

Entity, build/model, motion roles, defining attack clip, equipment, reference.
Generator command and exactly which files it overwrites. Reused clips/assets.
Sound cues, mapped placeholders, sources/licenses for any new downloaded assets.

## Encounters and review

Solo and paired placement names/coordinates. Pose sheet and animated review
commands/paths. Focused tests, build/render results, and known limitations.

## Playtest notes

Date, observations, changed values, and remaining questions. Automated test status
and human playtest status are separate.
